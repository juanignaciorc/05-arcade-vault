## Project

Arcade Vault — a platform for playing games online and competing for the highest score. The repo is currently a fresh `create-next-app` scaffold (App Router, TypeScript, Tailwind) with no game/vault features implemented yet; `app/page.tsx` is still the default template.

## Commands

```bash
npm run dev     # start dev server (Turbopack)
npm run build   # production build
npm run start   # run the production build
npm run lint    # eslint (flat config, eslint.config.mjs)
```

There is no test runner configured yet — do not assume Jest/Vitest exist.

## Stack notes (non-default configuration to be aware of)

- **Next.js 16.4.6 / React 19.3 canary-ish versions** — APIs may differ from older training data; per `AGENTS.md`, consult `node_modules/next/dist/docs/` for the actual installed version's behavior before assuming standard Next.js conventions.
- `next.config.ts` enables experimental flags that change framework behavior:
  - `cacheComponents: true` — component-level caching is on.
  - `partialPrefetching: true`
  - `experimental.agentFeedback: true`
- Tailwind CSS v4 is wired through Turbopack via a custom loader rule in `next.config.ts` (`@tailwindcss/turbopack`), not the standard PostCSS pipeline — don't add a `tailwind.config.js`/PostCSS config expecting it to be picked up the v3 way. Theme tokens are defined inline in `app/globals.css` via `@theme inline`.
- Path alias `@/*` maps to the repo root (`tsconfig.json`), not `src/`.
- `app/layout.tsx` uses the Next 16 typed `LayoutProps<"/">` helper type instead of the classic `{ children: React.ReactNode }` prop typing.
- `AGENTS.md` contains an auto-managed block regenerated by `next dev` (`<!-- BEGIN/END:nextjs-agent-rules -->`) — leave it in place; committing it is expected, don't strip it out as cruft.

## Architecture

There is no custom architecture yet beyond the standard Next.js App Router layout (`app/layout.tsx`, `app/page.tsx`, `app/globals.css`). When building out Arcade Vault's actual features (games, scoring/leaderboard, auth), establish the structure fresh rather than assuming any existing convention.
